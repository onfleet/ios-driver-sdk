DriverManaging

public protocol DriverManaging : AnyObject

The primary interface for managing the driver lifecycle, task operations, and related settings.

Overview

DriverManaging provides methods and properties for controlling all aspects of driver operations, including:

  • Duty status — going on and off duty
  • Task management — starting, completing, and self-assigning tasks
  • Driver profile — uploading profile images and updating profile details
  • Organization settings — checking feature flags and task requirements

Use the properties on this protocol to observe changes to driver state, active tasks, and assigned tasks. Many operations post notifications (e.g., .driverDidGoOnDuty, .driverDidStartTask) that you can observe for UI updates.

Examples

// Check duty status and go on duty
if !driverManager.isOnDuty {
    driverManager.setDutyStatus(goOnDuty: true) { result in
        switch result {
        case .success:
            print("Driver is now on duty")
        case .failure(let error):
            print("Failed to go on duty: \(error)")
        }
    }
}

// Start a task
if let task = driverManager.assignedTasks.first {
    driverManager.start(task: task) { result in
        switch result {
        case .success:
            print("Task started")
        case .failure(let error):
            print("Failed to start task: \(error)")
        }
    }
}

  • setDutyStatus(goOnDuty:completion:)

    Sets the driver’s duty status.

    When going on duty, this operation fails if location permission is not fully granted. See LocationManaging for more information.

    When going off duty, this operation fails if there is an active task.

    On success, .driverDidGoOnDuty or .driverDidGoOffDuty is posted.

    Note

  • complete(task:completionDetails:completion:)

    Completes the active task with the provided completion details.

    Some completion details may be required by the task or the organization’s settings. Before completing a task, check the following requirements and warnings:

    Required checks:

    • isBarcodeScanningRequired(for:)
    • isAgeVerificationRequired(for:)

    Optional warning checks:

    • shouldWarnOnOptionalNotesAttachment(for:)
    • shouldWarnOnOptionalPhotoAttachment(for:)
    • shouldWarnOnOptionalSignatureAttachment(for:)

    This operation fails if:

    • The driver is off duty.
    • The task is not active.
    • The task is already completed.
    • Required completion details are missing.

    On success, .driverDidCompleteTask is posted.
