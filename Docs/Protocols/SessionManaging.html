SessionManaging

public protocol SessionManaging: AnyObject,
                                 Sendable

The interface for authentication and account management.

Overview

SessionManaging handles driver authentication and organization account management. A driver’s phone number can be associated with multiple organizations. After a successful login, the SessionManaging instance provides:

  • An isAuthenticated flag (observable via authenticated$)
  • The list of available accounts
  • An active account representing the current organization

For drivers with multiple organizations, use changeActiveAccount(to:) to switch between them.

Examples

// Log in
let credentials = Credentials(
    phoneNumber: PhoneNumber(E164: "+14155552671"),
    password: "password",
    usedAutoFill: false
)
session.login(
    credentials: credentials,
    newPasswordProvider: { callback in
        // Present new-password UI and call callback with result
    },
    SMSVerificationCodeProvider: nil,
    activityStatus: { status in
        // Update activity indicator based on status
    },
    completion: { result in
        switch result {
        case .success(let password):
            print("Logged in successfully")
        case .failure(let error):
            print("Login failed: \(error)")
        }
    }
)

Authentication

  • isAuthenticated

    A Boolean value indicating whether the driver is currently authenticated.

    Observe changes using authenticated$.

    Declaration

    Swift

    var isAuthenticated: Bool { get }
  • authenticated$

    An observable that emits the current authentication state.

    When the value becomes false, present the login UI. When true, show the main application flow.

    Note

    The driver can be logged out at any time (e.g., when a dispatcher removes the driver from an organization or an unrecoverable authentication failure occurs). Observing this property is strongly recommended.

    Declaration

    Swift

    var authenticated$: Observable<Bool> { get }
  • login(credentials:newPasswordProvider:SMSVerificationCodeProvider:activityStatus:completion:)

    Logs the driver in with the provided credentials.

    During the login flow, the activityStatus closure is called each time the LoginStatus changes, allowing you to update the UI. The flow may be interrupted to request SMS verification or a new password.

    On success:

    • isAuthenticated becomes true.
    • The accounts list is populated.

    • An active account is set.

    Declaration

    Swift

    func login(credentials: Credentials,
           newPasswordProvider: @escaping NewPasswordProvider,
           SMSVerificationCodeProvider: SMSCodeProvider?,
           activityStatus: @escaping LoginActivityStatusProvider,
           completion: @escaping LoginCompletionHandler)

    Parameters

    credentials

    The driver’s login credentials.
    newPasswordProvider

    Called if the SDK detects that the driver is using a temporary password. Present a UI for the driver to set a new password and pass it back to the SDK via the callback.
    SMSVerificationCodeProvider

    Called if SMS verification is required. Present a UI for the driver to enter the code and pass it back via the callback.
    activityStatus

    Called each time the login status changes.
    completion

    Called when the operation finishes. On success, contains the effective password (which may differ from the original if a new password was set).
  • logout(force:started:completion:)

    Logs the driver out and removes all local data.

    If the driver is on duty, this operation first attempts to go off duty. It may fail if going off duty is not possible (e.g., an active task exists). Set force to true to bypass this check.

    Important

    Forcing logout may leave the server in an inconsistent state because tokens are not properly invalidated. Use with caution.

    Declaration

    Swift

    func logout(force: Bool,
            started: (@Sendable () -> Void)?,
            completion: LogoutCompletionHandler?)

    Parameters

    force

    Pass true to ignore errors and force the logout.
    started

    Called when the logout operation begins. Use this to present a progress indicator in the UI.
    completion

    Called when the operation finishes.
  • resetPassword(for:completion:)

    Resets the driver’s password.

    A temporary password is sent to the driver via SMS. The driver can then log in with the temporary password and will be prompted to set a new one.
