LocationManaging

public protocol LocationManaging : AnyObject

Provides access to the driver’s GPS location and location authorization status.

Overview

LocationManaging exposes the driver’s current location and the authorization state of location services. The SDK requires “Always” location access with full accuracy enabled before the driver can go on duty.

Use the observable properties (e.g., lastLocation$, isFullyAuthorized$) to keep your UI in sync with location and permission changes.

Examples

// Check location authorization before going on duty
if !locationManager.isFullyAuthorized {
    // Prompt the user to grant "Always" location permission
    // with full accuracy enabled
}

// Observe the last known location
locationManager.lastLocation$.observe { location in
    if let location {
        print("Current location: \(location.coordinate)")
    }
}
