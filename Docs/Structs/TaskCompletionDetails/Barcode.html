Barcode

public struct Barcode: Hashable,
                       Sendable

A barcode captured during task completion.

Represents a barcode that was scanned, manually entered, or verified as part of the task completion process.

Properties

  • id

    The unique identifier for this barcode.

    This property contains a unique identifier that distinguishes this barcode from others in the same task completion. The identifier is used for tracking and auditing purposes.

    Declaration

    Swift

    public var id: String
  • data

    The base64 encoded barcode data.

    This property contains the actual barcode data encoded as a base64 string. The data represents the captured barcode content from scanning, manual entry, or application verification. For failed captures, this may be empty or contain partial data.

    Declaration

    Swift

    public var data: String
  • symbology

    The type of barcode symbology.

    This property identifies the barcode format that was captured or attempted. Common values include:

    • “QR_CODE” - QR Code format
    • “CODE_128” - Code 128 format
    • “CODE_39” - Code 39 format
    • “EAN_13” - EAN-13 format
    • “UPC_A” - UPC-A format
    • “MANUAL” - Manual entry

    Declaration

    Swift

    public var symbology: String
  • wasRequested

    Indicates whether this barcode was requested to be captured.

    This property is true if the barcode was specifically requested for capture as part of the task requirements. It is false if the barcode was captured voluntarily or for other purposes.

    Declaration

    Swift

    public var wasRequested: Bool
  • failure

    Failure information if barcode capture failed.

    This property contains details about why the barcode capture failed, including a reason identifier and optional notes. It is nil if the barcode was successfully captured.

    Declaration

    Swift

    public var failure: Failure?
  • deviceID

    The device identifier where the barcode was captured.

    This property contains the unique identifier of the device that performed the barcode capture. It is used for auditing and tracking purposes in internal builds.

  • location

    The location where the barcode was captured.

    This property contains the geographical coordinates where the barcode capture occurred. It is used for location-based auditing and tracking in internal builds.

  • time

    The timestamp when the barcode was captured.

    This property contains the exact time when the barcode capture occurred. It is used for temporal auditing and tracking in internal builds.

  • init(id:data:symbology:wasRequested:failure:deviceID:location:time:)

    Creates a new barcode instance with full metadata.

    This initializer is available only in internal builds and provides access to additional metadata including device information, location, and timestamp.

  • init(id:data:symbology:wasRequested:failure:)

    Creates a barcode instance for task completion.

    Examples

    // Create a successful barcode capture (scanned)
let scannedBarcode = TaskCompletionDetails.Barcode(
    id: "barcode_123",
    data: "SGVsbG8gV29ybGQ=",
    symbology: "QR_CODE",
    wasRequested: true,
    failure: nil
)

// Create a manually entered barcode
let manualBarcode = TaskCompletionDetails.Barcode(
    id: "barcode_456",
    data: "MTIzNDU2Nzg5",
    symbology: "MANUAL",
    wasRequested: true,
    failure: nil
)

// Create a failed barcode capture
let failedBarcode = TaskCompletionDetails.Barcode(
    id: "barcode_789",
    data: "",
    symbology: "CODE_128",
    wasRequested: true,
    failure: TaskCompletionDetails.Barcode.Failure(
        reasonID: "CAPTURE_FAILED",
        notes: "Poor image quality"
    )
)
